# Todo-App-v2
An upgraded version from my original todo app

## Features

- Create and delete notes
- Mark each todo as complete
- Filter completed/incomplete/active todos
- Clear all completed todos
- Indicator of the current number of incomplete todos
- Apply light or dark theme (gets saved across refreshes in localStorage)

- [ ] Apply drag & drop for easy reordering
